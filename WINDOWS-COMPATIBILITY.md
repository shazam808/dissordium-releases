# Совместимость Dissordium с Windows

**Версия: Dissordium 1.0.0 Beta**

## Поддерживаемые операционные системы

| Операционная система | Статус |
|---|---|
| Windows 10 22H2 x64, сборка 19045 | Работоспособность подтверждена пользовательской проверкой |
| Windows 11 x64 | Работоспособность подтверждена пользовательской проверкой |
| Windows ARM64 | Совместимость не подтверждена |
| Windows 32-bit | Не поддерживается |

## Windows 10

Dissordium может использоваться на Windows 10 22H2 x64, начиная со сборки 19045.

Работоспособность на этой операционной системе подтверждена пользовательской проверкой.

Полная матрица сетевых, аварийных и длительных испытаний ещё не завершена.

Более старые версии Windows 10 не входят в заявленную проверенную конфигурацию.

## Windows 11

Dissordium работает на 64-разрядной Windows 11.

Подтверждены запуск приложения и пользовательские проверки основных функций.

На проверенном маршруте Windows 11 также подтверждена передача HTTPS и DNS через системный VPN-туннель после исправления ранее воспроизводившегося тайм-аута.

При этом отдельные аварийные сценарии продолжают исследоваться.

## Системные требования

- Windows 10 22H2 x64 (19045) или Windows 11 x64.
- Около 600 МБ свободного места, дополнительно к временному месту установки.
- Необходимые системные сетевые компоненты.
- Права администратора для установки и отдельных сетевых операций.
- Совместимая VPN-конфигурация для использования VPN-функций.

Необходимая среда .NET включена в поставку согласно текущей конфигурации установщика.

## Ограничения проверки

Дополнительные испытания необходимы для:

- Native IPv6.
- DNS в различных сетевых конфигурациях.
- Длительной нагрузки.
- Аварийного завершения сетевых процессов.
- Восстановления Windows после сна.
- Переключения сетей.
- Разных VPN-провайдеров и протоколов.
- Отдельных функций Discord Media.

## Известные проблемы

Ранее наблюдалась ошибка `WFP_E_IN_USE`, которая после аварийного завершения сетевых компонентов мешала повторному запуску обхода.

Её причина пока не установлена.
