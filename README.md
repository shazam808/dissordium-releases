# Dissordium

**Ваш интернет. Ваш маршрут.**

Dissordium — приложение для Windows, объединяющее Smart Bypass, VPN-подключения и гибкую маршрутизацию сетевого трафика в одном интерфейсе.

Выбирайте способ подключения для отдельных сервисов, управляйте собственными VPN-конфигурациями и контролируйте состояние сетевых компонентов.

## Возможности

### Smart Bypass

Smart Bypass позволяет назначать отдельным сервисам разные способы подключения:

- **Direct** — обычное подключение без дополнительного туннеля.
- **DPI Bypass** — выборочный обход сетевых ограничений.
- **VPN** — использование выбранной VPN-конфигурации.

Создавайте профили и настраивайте маршруты в соответствии со своими потребностями.

### VPN Routing

Dissordium поддерживает работу с совместимыми VPN-конфигурациями сторонних провайдеров.

В приложении можно:

- Импортировать поддерживаемые VPN-конфигурации.
- Управлять VPN-серверами.
- Работать с поддерживаемыми подписками.
- Выбирать необходимые маршруты.
- Проверять состояние подключения.

Dissordium не предоставляет собственную VPN-подписку в составе приложения.

Доступность подключения зависит от конфигурации, сервера и сетевых условий.

### Network Diagnostics

Встроенные диагностические инструменты помогают отслеживать состояние сетевых компонентов, анализировать подключения и выявлять возможные проблемы.

### Пользовательские профили

Настраивайте сервисы, сетевые стратегии и маршруты.

Пользовательские настройки и конфигурации сохраняются локально и могут переноситься предусмотренными средствами управления данными.

## Системные требования

- Windows 10 22H2 x64 (сборка 19045) или Windows 11 x64.
- Около 600 МБ свободного места и дополнительное пространство для установки.
- Права администратора для операций, требующих доступа к системным сетевым компонентам.

Работоспособность на Windows 10 и Windows 11 подтверждена пользовательскими проверками.

Полная матрица сетевых и аварийных испытаний ещё не завершена.

Подробнее: [Совместимость с Windows](WINDOWS-COMPATIBILITY.md).
