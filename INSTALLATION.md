# Установка Dissordium

## Системные требования

Dissordium 1.0.0 Beta предназначен для:

- Windows 10 22H2 x64, сборка 19045.
- Windows 11 x64.

Работоспособность приложения на обеих ОС подтверждена пользовательскими проверками. Полная матрица сетевых испытаний ещё не завершена.

Для установки и работы отдельных сетевых компонентов могут потребоваться права администратора.

## Скачивание

Для скачивания:

1. Перейдите в [GitHub Releases](https://github.com/shazam808/dissordium-releases/releases).
2. Выберите опубликованный релиз Dissordium 1.0.0 Beta.
3. Скачайте файл `Dissordium-Setup-1.0.0-Beta-x64.exe`.
4. Запустите установщик.

[Dissordium 1.0.0 Beta](https://github.com/shazam808/dissordium-releases/releases/tag/v1.0.0-beta) доступен публично с отметкой Pre-release.

К выпуску приложены три файла:

- `Dissordium-Setup-1.0.0-Beta-x64.exe` — установщик для Windows 10/11 x64.
- `THIRD_PARTY_SOURCES.zip` — исходные материалы сторонних компонентов и лицензионные уведомления; для обычной установки скачивать архив не требуется.
- `SHA256SUMS.txt` — контрольные суммы SHA-256 установщика и архива.

Вложения доступны для скачивания без доступа к приватному репозиторию исходного кода.

## Проверка контрольных сумм

Скачайте `SHA256SUMS.txt` из того же выпуска, что и установщик. В PowerShell, открытом в папке загрузки, выполните:

```powershell
Get-FileHash -LiteralPath '.\Dissordium-Setup-1.0.0-Beta-x64.exe' -Algorithm SHA256
```

Сравните поле `Hash` с первой колонкой строки этого файла в `SHA256SUMS.txt`. Регистр букв не имеет значения. Если скачали архив сторонних исходников, проверьте его отдельно:

```powershell
Get-FileHash -LiteralPath '.\THIRD_PARTY_SOURCES.zip' -Algorithm SHA256
```

Суммы должны полностью совпадать. При несовпадении не запускайте установщик и не используйте архив: повторите скачивание из того же выпуска. Сам `SHA256SUMS.txt` не включает собственную контрольную сумму.

SHA-256 позволяет проверить целостность файла, но не заменяет цифровую подпись издателя.

## Установка

1. Запустите установщик.
2. Следуйте инструкциям мастера.
3. При необходимости подтвердите запрос прав администратора.
4. Дождитесь завершения установки.
5. Запустите Dissordium.

Отдельной страницы принятия лицензионных условий в текущем мастере установки нет. Условия использования доступны в документации проекта и материалах поставки.

## Первый запуск

После запуска откройте раздел **«Обзор»**.

Здесь можно ознакомиться с текущим состоянием приложения и основными функциями управления подключением.

Для настройки маршрутизации используйте соответствующие разделы приложения.

Для проверки сетевых компонентов откройте **«Диагностика»**.

Если вы хотите использовать VPN, импортируйте совместимую конфигурацию своего VPN-провайдера.

## Обновление и переустановка

Установщик поддерживает сценарии **«Обновить»** и **«Переустановить»**.

При обнаружении существующей установки выберите подходящий вариант.

Перед заменой файлов установщик проверяет их доступность. Если необходимый файл заблокирован другим процессом, обновление может быть остановлено до внесения изменений.

При обычных сценариях обновления и переустановки пользовательские данные сохраняются.

Перед крупным обновлением рекомендуется дополнительно создать резервную копию настроек.

## Восстановление предыдущей версии

Если новая версия работает некорректно, можно использовать ранее сохранённый установщик предыдущей версии, если такой сценарий поддерживается соответствующей сборкой.

Это не является гарантированным автоматическим откатом системы после любого сбоя.

Перед восстановлением рекомендуется сохранить пользовательские данные.

## Удаление

Для удаления используйте стандартные средства Windows или предусмотренный мастер удаления.

Если необходимо сохранить пользовательские профили и VPN-конфигурации, не удаляйте вручную папку User Data.

## Возможные проблемы

Если возникают ошибки:

1. Проверьте совместимость Windows.
2. Убедитесь, что необходимые файлы приложения не заблокированы.
3. Откройте раздел «Диагностика».
4. Ознакомьтесь с [известными проблемами](KNOWN-ISSUES.md).
5. Не изменяйте вручную системные маршруты и DNS без необходимости.
