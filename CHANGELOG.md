# История изменений

Здесь публикуются основные изменения официальных версий Dissordium.

Внутренние идентификаторы сборок в пользовательской истории изменений не указываются.

## 1.0.0 Beta

Первая бета-версия Dissordium для Windows.

### Основные возможности

- Smart Bypass с маршрутами Direct, DPI Bypass и VPN.
- Управление пользовательскими сервисами.
- Создание и редактирование профилей.
- Интеграция сетевых движков DPI Bypass и VPN.
- Импорт поддерживаемых VPN-конфигураций.
- Работа с поддерживаемыми VPN-подписками.
- Управление VPN-серверами.
- Диагностика сетевых компонентов.
- Управление пользовательскими настройками и данными.
- Фирменный интерфейс Dissordium.

### Исправления сетевых компонентов

- Исправлен воспроизводимый тайм-аут HTTPS через системный VPN на проверенном маршруте Windows 11.
- Подтверждена передача HTTPS и DNS через VPN-туннель.
- Исправлен подтверждённый промежуток без блокировки защищаемого трафика при падении отдельного процесса Kill Switch.
- Уточнена диагностика восстановления DNS: изменения динамических интерфейсов больше не смешиваются с изменением настроек исходных сетевых адаптеров.

### Улучшения установщика

- Добавлены сценарии обновления и переустановки.
- Реализована предварительная проверка доступности заменяемых файлов.
- Проверка предотвращает частичное обновление, если необходимый файл заранее заблокирован.
- Проверено сохранение пользовательских данных при основных сценариях установки и обновления.
- Подготовлена возможность восстановления предыдущей версии с использованием сохранённого установщика.

Установщик не гарантирует автоматический полный откат при любых возможных сбоях.

### Подготовка распространения

- Подготовлен отдельный репозиторий официальных релизов.
- Настроена автоматизация сборки и проверок.
- Подготовлен установщик Windows x64.
- Добавлены пользовательская документация и лицензионные материалы.

### Известные ограничения

- Ошибка WFP_E_IN_USE, ранее наблюдавшаяся после аварийного завершения сетевых компонентов, требует дальнейшего исследования.
- Не завершена полная проверка native IPv6/DNS, длительной эксплуатации, сна Windows и смены сети.
- Отдельные сценарии Discord, включая звонки и трансляции, требуют дополнительной проверки.
- Совместимость некоторых VPN-конфигураций зависит от используемого протокола и транспорта.
- Установщик пока не подписан сертификатом издателя.

Подробнее: [Известные проблемы](KNOWN-ISSUES.md).
